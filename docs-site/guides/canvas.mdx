The canvas is an infinite board built on [tldraw](https://tldraw.dev). Everything you make (images, videos, text, shapes, frames, web pages, 3D models) lives on it, and everything stays editable.

## Layout

- **Left**: the Agent panel. Dock it left or right, maximize it, or collapse it.
- **Top**: project name, pages, and the Reference and My Assets panels.
- **Bottom**: tools (Select, Comment, Draw, Insert) and the **Image Generation** / video generation button.
- **Bottom right**: background color, Layers, Generated Files, minimap and zoom.

## Working with shapes

- **Text** with any font, weight, size, color, stroke, alignment, spacing, decoration and case. Brand kit fonts are available too.
- **Shapes**: rectangle, ellipse, polygon, star, line and arrow, with inner, center or outer strokes (solid, dashed, dotted) and linear or radial gradient fills.
- **Draw** with any color and width, and sticky notes from the Insert menu.
- **Uploads**: drop images, videos, PDFs (each page becomes an image in a frame), Lottie animations, 3D models (GLB, GLTF, OBJ, FBX, STL, PLY) and HTML widgets.

Selecting several shapes shows a toolbar to tidy up, group, merge layers, align, distribute and download (including PSD export).

## Frames

Frames are smart artboards. A frame can have a fixed or hugging width and height, auto layout that re-flows when children change, a locked aspect ratio and an image fill. From the frame toolbar you can generate straight into the frame, download everything as a ZIP, export, or play the frames as a fullscreen slideshow.

## Layers

The **Layers** panel lists every shape on the page with hide and lock toggles. Split layer results (see [Image tools](/guides/image-tools#split-layers)) show up here as a frame with one entry per layer.

## Comments

Use the **Comment** tool to pin feedback on the canvas: click a point, or draw a lasso or a box around an area. A comment on an image can be run as an edit. The comments panel lists all comments with an open / done filter, and can add them to the chat or run them all at once.

**Touch edit**: Ctrl + click an image (or hover and press C) to mark an object, then describe the change. Shift + click adds more mark points.

## History and export

- Projects save automatically. **Canvas history** keeps snapshots you can restore.
- Export a selection or a page as PNG, JPG or PDF at any scale, or as **PPTX**: one slide per frame or page, either as images or with editable text, images and shapes.
- If the same project is open in another tab, ComfyArt warns you and stops saving in the stale tab so you do not overwrite newer work.
