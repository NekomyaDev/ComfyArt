ComfyArt is an **AI design canvas** that runs entirely on your own ComfyUI: an infinite canvas for posters, social images, slides and short videos, a design agent that works on that canvas with real tools, and every image and video model running on your own GPU.

## Why ComfyArt

<CardGroup cols={3}>
  <Card title="Fully local" icon="house-laptop">
    Every model runs in your ComfyUI. Nothing is uploaded, and ComfyArt never stores credentials.
  </Card>
  <Card title="Open workflows" icon="diagram-project">
    Each canvas action is a plain ComfyUI API workflow in `workflows/`, built from core nodes wherever possible.
  </Card>
  <Card title="Agent-ready" icon="plug" href="/guides/mcp">
    An MCP server lets the built-in agent, or any local MCP client, look at the canvas and edit it.
  </Card>
</CardGroup>
