## 首页

打开 [http://127.0.0.1:8188/comfyart/](http://127.0.0.1:8188/comfyart/) 就会进入首页。

<Frame>
  <img src="/images/home.webp" alt="ComfyArt 首页" />
</Frame>

- **你想设计什么？**：输入需求并发送，ComfyArt 会新建一个项目，把需求交给 [Agent](/zh/guides/agent)。用 **+** 附加图片，或者把模式切到图像、视频，直接生成。
- **帮你做：**：快捷入口（社交媒体、电商、品牌、创意、网站）会帮你填好提示词的前半句。
- **最近项目** 显示你最近的画布；**查看全部** 打开项目库。
- **从 Skill 开始** 列出内置技能和你自己的技能（标着「我的」）。选一个就会新建一个带上该技能的项目。

左侧栏有 **新建项目**、**首页**、**项目库** 和设置菜单。

## 项目

<Frame>
  <img src="/images/projects.webp" alt="项目库" />
</Frame>

项目库列出所有项目，并显示画布预览。在卡片菜单里可以重命名或删除项目，也可以用 **选择** 勾选多个（或 **全选**）一起删除。删除项目会删掉它的画布、对话和保存的版本；生成的图片和视频仍留在 ComfyUI 的输出目录里。

每个项目对应一个网址 `/comfyart/?project=<id>`，保存在 ComfyUI 用户目录的 `comfyart/projects/` 下。

## 项目内

在项目里点左上角的 Logo 打开项目菜单。

<Frame>
  <img src="/images/project-menu.webp" alt="项目菜单" style={{ maxWidth: '400px' }} />
</Frame>

这里可以回到首页或项目库，新建或删除项目，打开 **画布历史**（恢复快照），导入图片，执行撤销、创建副本和缩放命令，打开 Agent 的 **记忆**，以及给项目关联 **项目品牌套件**。每条发给 Agent 的消息都会带上关联的套件。

## 设置

齿轮按钮（项目里在右上角，首页在左下角）打开设置菜单。

<Frame>
  <img src="/images/settings-menu.webp" alt="设置菜单" style={{ maxWidth: '360px' }} />
</Frame>

| 设置 | 选项 |
|---|---|
| 语言 | 中文或 English，即时切换 |
| 主题 | 浅色、深色或跟随系统 |
| 对话区位置 | Agent 面板放在左侧或右侧 |
| 快捷键 | 完整的快捷键列表（也可以按 `?` 打开） |
| 页面在后台时推送系统通知 | 标签页在后台时任务完成，会弹浏览器通知 |
