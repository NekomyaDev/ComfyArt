画布是基于 [tldraw](https://tldraw.dev) 的无限白板。你做出来的所有东西（图片、视频、文字、形状、画板、网页、3D 模型）都放在上面，而且始终可以再编辑。

## 界面布局

- **左侧**：Agent 面板。可以停靠在左边或右边，也可以最大化或收起。
- **顶部**：项目名、页面，以及「参考」和「我的素材」面板。
- **底部**：工具（选择、评论、涂鸦、插入）和 **图像生成** / 视频生成按钮。
- **右下角**：背景色、图层、生成文件、小地图和缩放。

## 形状与内容

- **文字**：任意字体、字重、字号、颜色、描边、对齐、间距、装饰线和大小写，也能用品牌套件里的字体。
- **形状**：矩形、椭圆、多边形、星形、直线和箭头，描边可以是内、中、外（实线、虚线、点线），填充支持线性和径向渐变。
- **涂鸦**：任意颜色和粗细；插入菜单里还有便签。
- **上传**：可以拖入图片、视频、PDF（每页变成一张图，放在一个画板里）、Lottie 动画、3D 模型（GLB、GLTF、OBJ、FBX、STL、PLY）和 HTML 小组件。

多选时会出现工具栏：自动整理、编组、合并图层、对齐、分布和下载（包括导出 PSD）。

右键菜单包括剪贴板、层级、编组、翻转、锁定、替换、发送到生成器、批量重命名和导出。

## 画板

画板是智能画板：宽高可以固定或随内容自适应，自动布局会在子元素变化时重新排列，还能锁定宽高比、设置图片填充。画板工具栏可以直接往画板里生成内容、打包 ZIP 下载、导出，或者全屏幻灯片播放。

## 图层

**图层** 面板列出当前页面的所有形状，可以隐藏和锁定。图层拆分的结果（见[图像工具](/zh/guides/image-tools)）会以一个画板的形式出现在这里，每层一项。

## 评论

用 **评论** 工具在画布上钉反馈：点一个位置，或用套索、方框圈出一块区域。图片上的评论可以直接作为修改去执行。评论面板列出所有评论，可以按未完成 / 已完成筛选，也可以把评论加到对话里，或一次全部执行。

**点选修改**：按住 Ctrl 点击图片（或悬停后按 C）标记一个物体，然后描述要怎么改。Shift + 点击可以再加标记点。

## 历史与导出

- 项目自动保存。**画布历史** 会保留快照，可以随时恢复。
- 选中内容或整页都可以导出为任意倍率的 PNG、JPG 或 PDF，也能导出 **PPTX**：每个画板或每页一张幻灯片，可以选纯图片，或者文字、图片和形状都可编辑。
- 同一个项目在另一个标签页里也打开时，ComfyArt 会提醒你，并让旧标签页停止保存，避免覆盖更新的内容。
