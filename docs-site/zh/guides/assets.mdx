## 我的素材

<Frame>
  <img src="/images/assets.webp" alt="我的素材面板" style={{ maxWidth: '360px' }} />
</Frame>

顶部栏的 **我的素材** 里有两类东西：

- **文件**：ComfyUI 资产库里的所有图片和视频，可以按「生成」或「上传」筛选，也可以搜索。缩略图随滚动按需加载；预览显示不出来时，会换成一个默认图标。
- **品牌套件、角色、产品、自定义**：你自己建的具名素材。在画布上选中内容，加到其中一组，就能在提示词里用 `@` 引用。

点任意一项就会把它放到画布上。

## 品牌套件

品牌套件收集具名的颜色角色、Logo、字体和文字规范。你可以：

- 从一份品牌文件（图片或 PDF）里自动提取套件。
- 上传字体文件（注册后画布文字可用）或选择本机字体。
- 把某个套件设为新项目的默认套件，或用 **使用此套件设计（新建项目）** 新建一个关联它的项目。
- 复制套件、设置封面。

项目关联了品牌套件后，每条发给 Agent 的消息都会带上这套品牌信息。

## 参考板

顶部栏的 **参考** 面板用来收集项目的参考图：可以上传，从我的素材里挑，或者把画布上选中的图加进来。可以按来源（上传、画布、素材库）筛选，按最新或名称排序，并打开、重命名、复制、剪切、创建副本、导出或删除。

每张参考图都有 **风格分析** 和 **构图分析**（由 Agent 完成，分析结果可以直接加进提示词），以及 **生成变体**。**生成情绪板** 会把参考图排进一个画板。
